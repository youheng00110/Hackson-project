Demo
==========
概览（要解决的问题）
------------

目标：给定 N人的当前位置 + 出行方式（步行/驾车/公交/骑行）＋出发时间，自动找出一个或若干“候选会面点”，使得每个人到该点的通勤时间差异较小（比如到达时长接近、或最大到达时间最小化），并在真实地图上显示（用高德/百度地图 API 做路由/时间估算和可视化）。
