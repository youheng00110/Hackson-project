## 🎯 核心功能操作

### 1. 侧边栏交互
- 点击侧边栏顶部的 **折叠按钮**（左箭头图标）可收起/展开侧边栏
- 收起时宽度变为 60px，仅显示图标
- 展开时宽度为 240px，显示图标和文字

### 2. 页面切换
- 点击左侧菜单项即可切换页面
- 选中菜单项会高亮显示（蓝色背景 + 左侧指示器）
- 页面切换时有淡入动画效果

### 3. 路由规则
| 路径 | 页面名称 | 说明 |
|------|---------|------|
| `#/home` | 首页 | 数据概览和快捷操作 |
| `#/multi-terminal` | 房间码多终端模式 | 创建/加入协作房间 |
| `#/single-terminal` | 单终端模式 | 原有的完整功能 |
| `#/developing` | 开发中 | 占位提示页面 |

### 4. 单终端模式
- 默认自动添加当前位置的用户
- 点击地图可选择位置并添加人员
- 至少需要 2 人才能计算会面点
- 支持自定义会面点类型
- 可调节搜索半径（1000m - 10000m）
- 可选择计算策略（综合/时差最小/距离差最小）

## 🔧 技术亮点

### 1. 轻量级路由
- 无需 react-router 等第三方库
- 基于原生 `location.hash` 和 `hashchange` 事件
- 提供 `router.js` 工具函数：
  - `getCurrentPage()` - 获取当前页面
  - `navigateTo(pageName)` - 跳转到指定页面
  - `listenRouteChanges(callback)` - 监听路由变化

### 2. 组件化设计
- 所有页面都是独立的函数式组件
- 使用 React Hooks（useState, useEffect, useCallback）
- 组件职责单一，易于维护

### 3. 样式模块化
- 每个组件都有独立的 CSS 文件
- 避免全局样式污染
- 使用中文注释说明功能和参数

### 4. 代码规范
- 所有注释使用中文
- 函数命名语义化
- 关键逻辑都有详细注释
