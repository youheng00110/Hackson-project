# 多人会面点推荐系统 - 快速开始指南

## 🚀 快速启动

### 1. 安装依赖
```bash
cd meeting-point-recommender/frontend
npm install
```

### 2. 配置环境变量
复制 `.env.example` 为 `.env`，并填写你的高德地图 API 密钥：
```bash
VITE_AMAP_KEY=你的 API 密钥
VITE_API_BASE_URL=http://localhost:3000
```

### 3. 启动开发服务器
```bash
npm run dev
```

访问地址：**http://localhost:5174/**

## 📱 功能导航

### 左侧菜单栏
- **首页** 🏠 - 数据概览、快捷操作、最近记录
- **房间码多终端模式** 👥 - 创建/加入协作房间
- **单终端模式** 👤 - 完整的会面点推荐功能（原有功能）
- **开发中** ⏳ - 占位页面

### 侧边栏交互
- 点击顶部的 **◀** 按钮可折叠/展开侧边栏
- 折叠后仅显示图标，展开后显示图标 + 文字

---

## 🎯 核心功能

### 首页 (`#/home`)
- 查看数据统计卡片
- 使用快捷操作按钮
- 浏览最近会面记录

### 单终端模式 (`#/single-terminal`)
1. **添加人员**：至少需要 2 人
   - 点击地图选择位置
   - 或搜索地址添加
2. **选择会面点类型**：
   - 咖啡馆、公园、美食、购物中心等
   - 支持自定义类型
3. **调节搜索半径**：1000m - 10000m
4. **选择计算策略**：
   - 默认推荐（综合）
   - 相对时差最小优先
   - 相对距离差最小优先
5. **查找会面点**：点击按钮开始计算
6. **AI 决策助手**：智能推荐最佳选择

### 房间码多终端模式 (`#/multi-terminal`)
- 创建新房间（功能开发中）
- 输入房间码加入现有房间（功能开发中）

## 🛠️ 技术栈

- **React 19** - UI 框架
- **Vite** - 构建工具
- **Font Awesome 6** - 图标库
- **原生 JavaScript** - 路由实现（无需 react-router）
- **高德地图 API** - 地图服务

## 📝 注意事项

1. **首次启动**：确保安装所有依赖
2. **API 密钥**：需要有效的高德地图 API 密钥
3. **端口占用**：如果 5173 端口被占用，会自动使用 5174
4. **网络要求**：需要联网访问高德地图服务
